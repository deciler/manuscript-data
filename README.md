# manuscript-data
Data and source files associated with the manuscript: U-shaped sedimentary microplastic distribution along the land-sea continuum in an urban mangrove wetland

This repository contains the data and analysis files associated with the manuscript.

* `Microplastic_Abundance_Water_and_Sediment.xlsx`
  Microplastic abundance data in water and sediment samples.

* `Water_Environmental_Parameters.xlsx`
  Environmental parameter data measured in water samples.

* `Sediment_Environmental_Parameters.xlsx`
  Environmental parameter data measured in sediment samples.

* `PCA_PC1_Analysis/`
  Data and scripts used for principal component analysis (PCA) of heavy metals and extraction of PC1.

* `Figure 3_GAM_Analysis/`
  Data and R scripts used for the generalized additive model (GAM) analysis presented in Figure 3.
